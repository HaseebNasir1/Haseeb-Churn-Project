# Bank Customer Churn Analysis

## Project Overview

This project analyses bank customer data to explore customer churn and demonstrate practical Excel data analysis skills.

The original dataset contained customer and account information that required cleaning, validation and consolidation before it could be used for analysis. I created a cleaned dataset by preparing the individual data sources and combining relevant customer and account information into a single analysis-ready table.

The project was completed as part of developing my practical data analytics skills and applying Excel techniques to a realistic business dataset.

## Business Problem

Customer churn is an important issue for businesses because losing existing customers can affect revenue and long-term growth.

The purpose of this project was to prepare customer data for analysis and create a reliable dataset that could be used to investigate customer behaviour and churn.

## Data Cleaning Process

The project involved:

- Reviewing the raw customer and account datasets
- Identifying and cleaning inconsistent data
- Checking for duplicate customer records
- Standardising values and formatting
- Creating separate cleaned versions of the source datasets
- Using Customer ID as the common identifier between datasets
- Using XLOOKUP to combine customer and account information
- Checking for unmatched records and formula errors
- Validating the final combined dataset

## Final Dataset

The cleaned dataset contains customer information including:

- Customer ID
- Credit Score
- Geography
- Gender
- Age
- Tenure
- Estimated Salary
- Account Balance
- Number of Products
- Credit Card Status
- Active Member Status
- Churn / Exit Status

This provides a structured dataset that can be used to investigate customer churn and identify patterns across different customer characteristics.
